# 设计令牌

## 色彩

| Token | 值 | 用途 |
| --- | --- | --- |
| Bone 骨白 | `#F4F0E6` | 页面底色 |
| Paper 纸白 | `#FBF8F0` | 卡片/面板底 |
| Ink 墨黑 | `#171614` | 正文/主按钮/标题 |
| Bronze 青铜 | `#8B7355` | 次级强调/图标/线框 |
| Bronze Dark | `#4E3A28` | 悬停/深强调 |
| Gold 暗金 | `#B49765` | 点缀/小标签/装饰线 |
| Line | `#D8CCB5` | 分隔线/描边 |
| Green | `#3E6B4F` | 高置信状态 |
| Amber | `#9A6A1F` | 待考证/警示状态 |

强调色仅用于少量点缀：状态标签、关键数据、连接线。

## 字体

| 层级 | 字体 | 字号 |
| --- | --- | --- |
| Hero / 大标题 | KaiTi / STKaiti / 楷体 | 70–80px（1440 画板） |
| 页面标题 | KaiTi | 48–54px |
| 章节标题 | KaiTi | 28–32px |
| 正文 | Microsoft YaHei | 15px / 行高 28px |
| 说明/元信息 | Microsoft YaHei | 11–13px / 行高 20–24px |

## 形状与阴影

- 卡片圆角：12–16px；小标签胶囊（999px）
- 描边：1px `Line`；证据链引用用 2px Gold 左线
- 阴影：`0 1px 2px rgba(23,22,20,.04), 0 10px 28px -18px rgba(23,22,20,.14)`
- Hover 阴影：`0 2px 4px rgba(23,22,20,.05), 0 18px 42px -22px rgba(23,22,20,.25)`

## 间距

- 页面外边距：左右 80px（1440 画板），顶部 64px
- 章节纵向间距：96–112px
- 卡片内边距：24–32px；字段行距 12–20px
