# 「殷契拾文」甲骨文数字史官 · 角色设定档

版本：v0.1（AI 概念设定稿阶段） · 品牌：殷契拾文——AI 甲骨文识别与学习研究平台

> 本文件锁定角色的形象与气质基准，供 AI 概念生图、后续人工建模或数字人
> 二次制作使用。AI 生成图为概念参考，不代表最终 3D 模型与正式上线的
> 数字人形象。

## 一、角色定位

| 项目 | 设定 |
|---|---|
| 角色标题 | 甲骨文数字史官 / 古文字数字讲解员 / AI 甲骨文知识助手 |
| 使用场景 | 殷契拾文平台的数字人文讲解、AI 识甲结果讲解、字形演变与知识问答 |
| 核心气质 | 博学、沉稳、克制、温润；历史厚重感 + 克制数字科技感 |
| 明确排除 | 普通古装 NPC、仙侠、玄幻、网红古风、偶像浓妆、赛博朋克过度科技化 |

## 二、人物形象

- 年轻东方男性，约 25 岁；五官端正、清俊但不网红化，具东方古典审美；
  眼神深邃、专注、有“神”，呈现长期研究古文字的学者气质。
- 表情沉静、自信、温和，有知识型人物的权威感，不做夸张表情。
- 黑色长发；传统束发与简洁古代发冠结合；发冠内融入浅刻甲骨文纹样
  （仅使用真实字形意象，如日、月、牛、马、鱼、鸟，不作随机乱码）。
- 皮肤真实细腻、自然毛发；无浓妆、无美颜感、无过度精致的偶像脸。

## 三、服装设计

- 定位：“商代史官服饰意象 + 中国传统汉服结构 + 现代数字科技细节”的原创设计。
- 主色：深玄黑、青铜灰、暗金、米白；暗金与青蓝仅作克制点缀。
- 宽袖长袍，层次丰富但简洁高级；衣袍、袖口、腰带、肩部融入浅刻甲骨文纹样。
- 腰间悬挂一枚青铜质感玉佩与小型甲骨简牍。
- 手持一片具有骨质、刻痕与岁月侵蚀感的“甲骨文数字档案牌”。
- 织物要求真实布料纹理，青铜要求真实氧化与金属质感，甲骨要求骨白/褐的
  自然侵蚀观感；所有纹样应像“刻痕”，不是廉价印花。

## 四、数字科技元素（克制使用）

- 半透明蓝白全息甲骨文字体、漂浮的甲骨字符、数字文字粒子；
- 微弱 HUD 数据界面、甲骨片扫描线、文字识别光效；
- 古文字可从实体甲骨纹理向数字粒子转化的意象。
- 原则：科技元素是“讲解工具的体现”，不得喧宾夺主；整体视觉仍以中国历史
  文化为核心。

## 五、核心视觉符号

甲骨、青铜器、商代文字、龟甲兽骨、古代史官、竹简、青铜纹饰、金文、
数字化文字、AI 全息界面。画面重点突出“甲骨文”，不泛化到普通中国风。

## 六、动作与镜头语言

- 正面全身：自然站立或半身正面站姿，一手轻托甲骨文数字档案牌，另一手做
  从容的讲解手势。
- 姿态端正、从容、专业，能联想到“识别 / 释义 / 历史讲解 / 字形演变 /
  知识问答”五类讲解。
- 概念图统一使用暗色“未来数字甲骨研究空间”：古代甲骨档案库与现代数字
  博物馆融合，可含大型甲骨数据库、青铜器轮廓、漂浮文字、数字屏幕；
  少量金色与青蓝色光线表达“古代文明 × 未来科技”。
